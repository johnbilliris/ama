# PR #159: API Python 3.15

## Individual plan and implementation

1. Compare the proposed Python pins with both API stages, installed runtime
   dependencies, native extensions, copied source, and the repaired baseline.
2. Build the actual ARM64 candidate using the approved feed. Resolve observed
   build prerequisites without unsupported ABI switches or dependency
   downgrades, keeping build tools out of the runtime image.
3. Verify the real 3.15 interpreter, imports and dependency consistency, then
   run API health, authentication, tenancy, RBAC, incident, alert, and signal
   regressions under that interpreter.
4. Run the candidate API image in the complete production-style local stack,
   assert its actual image/interpreter, check direct and frontend-proxied API
   routing, then commit and normally push to the original PR branch.

`linker cc not found` while compiling pydantic-core. Adding `build-essential`
only to the builder resolved that prerequisite. The non-root runtime retains
its existing minimal curl installation and contains no copied compiler tools.
No pydantic source patch, ABI-forward-compatibility flag, package-source
fallback, or unrelated version downgrade was used.
