# PR #147: Playwright 1.63.0

## Individual plan and implementation

1. Inspect the current runner/configuration, original proposal, and official
   [v1.63.0 release](https://github.com/microsoft/playwright/releases/tag/v1.63.0).
   Account for browser binaries being coupled to the Playwright package.
2. Pin `@playwright/test` to exact 1.63.0 and regenerate its graph while keeping
   unrelated dependencies, security overrides, and existing integrity records.
3. Validate frozen resolution, domain declarations, lint/types, production
   build, and unit tests. Install the matching Chromium build and Linux browser
   dependencies in the ephemeral test container, then execute the real
   configured Chromium/mobile acceptance projects.
4. Run the candidate production image in the full Compose stack, then commit
   and push normally to the existing PR branch.
