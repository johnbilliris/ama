Behavioral regression runs inside that Python 3.14 image:

```text
python -m pytest tests/unit/test_ingestion_*.py
  tests/integration/test_ingestion_pipeline.py
  tests/integration/test_ingestion_signal_repository_wiring.py
  tests/integration/test_idempotent_ingest.py
  tests/contract/test_ingest_pipeline.py tests/contract/test_ingestion_*.py
```

**116 tests passed, none skipped.** Four existing Tenacity deprecation warnings
remain. The final run mounts the real repository corpus read-only; the preceding
focused archive run passed 115 tests but skipped corpus idempotency because that
fixture directory was absent. The final result corrects that coverage gap.

After an observed missing async-test-plugin failure, `pytest-asyncio` was
installed only in the ephemeral test container using the explicit approved
Microsoft proxy. It is not added to the production runtime or dependency graph.
The final test container also passed `pip check`.

The complete Compose stack used the candidate ingestion image, reported Python
3.14.8 from the running worker, and reached eight healthy long-running services.
The API liveness, frontend root, and frontend-proxied API liveness routes each
returned HTTP 200. Task services were subsequently stopped; volumes were kept.

An unrelated local process occupied host port 10000. A session-only Compose
override used free host ports 11000-11002 for Azurite while preserving its
internal service endpoints. No unrelated process was stopped and no repository
Compose configuration was changed.
