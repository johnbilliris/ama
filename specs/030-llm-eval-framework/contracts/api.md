# API Contract: LLM Evaluation Framework

**Feature**: 030-llm-eval-framework
**Surface**: FastAPI router mounted at `/api/eval/*` in `apps/api`. All endpoints require Entra ID auth; trace endpoints additionally require an `eval-*` role (FR-022).

OpenAPI is generated by FastAPI; this document is the contract of record for the **routes, request/response shapes, and authorisation tiers**. Detailed request schemas live in `apps/api/app/models/eval/*.py` (Pydantic v2). The full OpenAPI doc is generated to `specs/030-llm-eval-framework/contracts/openapi.json` during `pytest tests/contract/test_eval_api.py`.

---

## Authentication & authorisation

- All routes: Entra ID bearer token; principal id captured in audit events.
- Tier-1 (summary) routes: any authenticated platform staff.
- Tier-2 (detail/trace) routes: `eval-author` ∨ `safety-reviewer` ∨ `governance-reviewer`.
- Mutating dataset/metric routes: `safety-reviewer` (datasets) ∨ `eval-author` (metrics in draft) ∨ `governance-reviewer` (override).
- Gate-override route: `governance-reviewer` AND a documented justification body.

## Datasets

### `POST /api/eval/datasets/{datasetId}/versions`

Publish a new immutable dataset version from an approved draft. Requires `safety-reviewer`.

Request:

```json
{
  "version": "1.0.0",
  "expectedCaseCount": 5000,
  "expectedHazardDistribution": {"structure-fire": 0.12, "bushfire": 0.12, "...": "..."}
}
```

Response `201`:

```json
{
  "datasetId": "disaster-response-core",
  "version": "1.0.0",
  "state": "published",
  "contentHash": "sha256:...",
  "caseCount": 5000,
  "distribution": {"structure-fire": 600, "bushfire": 600, "...": "..."},
  "manifestBlobUri": "https://.../datasets/disaster-response-core/1.0.0/manifest.json",
  "publishedAt": "2026-04-27T10:00:00Z"
}
```

Errors: `400 distribution-violates-min-share`, `409 version-exists`, `412 cases-not-approved`.

### `GET /api/eval/datasets`

List dataset families and their published versions.

### `GET /api/eval/datasets/{datasetId}/versions/{version}`

Return manifest. Tier-1.

### `GET /api/eval/datasets/{datasetId}/versions/{version}/cases`

Tier-2. Streams cases JSONL (or page-by-page when `?format=json`). Logs `dataset.cases.read`.

## Runs

### `POST /api/eval/runs`

Queue a new run.

Request:

```json
{
  "mode": "ad-hoc | scheduled-baseline | pr-fast-subset | progressive-delivery-full",
  "datasetRef": {"datasetId": "disaster-response-core", "version": "1.0.0", "subsetFilter": null},
  "modelRefs": [
    {"modelId": "openai/gpt-frontier", "version": "2026-04-01"},
    {"modelId": "openai/gpt-mid", "version": "2026-04-01"},
    {"modelId": "microsoft/phi-small", "version": "2026-04-01"}
  ],
  "metricSet": "disaster-core-v1",
  "policyId": "default-eval-policy",
  "policyVersion": "1.0.0",
  "baselineRunId": "01J..."
}
```

Response `202`:

```json
{
  "runId": "01J...",
  "status": "queued",
  "estimatedCostAud": 142.50,
  "estimatedDurationMinutes": 320
}
```

Validation:

- Reject before provisioning if `estimatedCostAud > policy.maxRunCostAud`.
- Reject if `mode == "pr-fast-subset"` and `estimatedDurationMinutes > policy.prFastSubsetMaxMinutes` (≤ 30).
- Reject if `mode == "progressive-delivery-full"` and `estimatedDurationMinutes > policy.maxRunDurationMinutes` (≤ 480).

Errors: `409 policy-violation`, `412 dataset-not-published`, `412 metric-not-active`, `403 insufficient-role`.

### `GET /api/eval/runs/{runId}` — Tier-1, no per-sample traces.

### `GET /api/eval/runs/{runId}/progress` — Tier-1; SSE when `Accept: text/event-stream` (FR-028).

### `POST /api/eval/runs/{runId}/cancel` — cancels in-flight run; triggers deprovisioning regardless of state.

### `GET /api/eval/runs?status=...&dataset=...&since=...&changeRef=...` — Tier-1 list/filter.

## Scorecards (two-tier, FR-022)

### `GET /api/eval/scorecards/{runId}` (Tier-1)

```json
{
  "runId": "01J...",
  "datasetVersion": "1.0.0",
  "models": [
    {"modelId":"openai/gpt-frontier","version":"2026-04-01","verdict":"pass","metrics":{"groundedness":{"mean":4.6,"pass":true,"deltaVsBaseline":0.1},"refusal-correctness":{"mean":0.97,"pass":true},"safety":{"mean":1.0,"pass":true},"tone-appropriateness":{"mean":4.4,"pass":true}}}
  ],
  "winnerByMetric": {"groundedness": "openai/gpt-frontier"},
  "overallWinner": "openai/gpt-frontier",
  "regressions": []
}
```

### `GET /api/eval/scorecards/{runId}/traces` (Tier-2)

Paged sample-level traces. Logs `scorecard.trace.read` per request.

### `GET /api/eval/scorecards/{runId}/traces/{caseId}/{modelId}` (Tier-2)

Full single-sample trace (input, output, scores, rationales).

### `GET /api/eval/scorecards/{runId}/export?format=json|html|evidence-bundle`

`evidence-bundle` is Tier-2 (signed zip per research D10). `json`/`html` summary are Tier-1.

## Release gate

### `POST /api/eval/gate/check`

Called from GitHub Actions and from the progressive-delivery promotion workflow. Idempotent on `(changeRef, mode)`.

Request:

```json
{
  "changeRef": "pr-12345",
  "mode": "pr-fast-subset",
  "modelRefs": [{"modelId":"openai/gpt-mid","version":"2026-04-01"}],
  "datasetRef": {"datasetId":"disaster-response-core","version":"1.0.0"},
  "baselineRunId": "01J..."
}
```

Response `200`:

```json
{
  "runId": "01J...",
  "verdict": "pass" | "fail" | "pending",
  "regressions": [{"metricId":"safety","modelId":"openai/gpt-mid","delta":-0.04,"threshold":0}],
  "scorecardUrl": "https://ama.../eval/runs/01J...",
  "evidenceBundleRef": null
}
```

### `POST /api/eval/gate/{runId}/override`

Tier: `governance-reviewer`. Body MUST include `justification` (≥ 50 chars), `approvers[]`, and a link to a written record. Emits `gate.override.applied` audit event and notifies the safety reviewer (FR-024).

## Concurrency, idempotency, errors

- `POST /api/eval/runs` and `POST /api/eval/gate/check` are not dedup'd across users (Edge Cases / Q9): two concurrent requests for the same `(model, dataset)` produce two distinct `runId`s.
- `POST /api/eval/gate/check` is idempotent **per `(changeRef, mode)`** so GH Actions retries don't multiply runs.
- Mutating routes return `Location` for the created resource and `ETag` where applicable.
- Standard error envelope: `{ "code": "policy-violation", "message": "...", "details": { ... } }`.

## Worker contract (Container Apps Job)

- **Entrypoint**: `python -m ama_eval.runner --run-id <runId>`.
- **Environment**: `RUN_ID`, `COSMOS_ENDPOINT`, `BLOB_ACCOUNT_URL`, `KEYVAULT_URI`, `APP_INSIGHTS_CONNECTION_STRING`, `FOUNDRY_PROJECT_ENDPOINT`. Managed identity provides credentials.
- **Inputs**: reads `EvaluationRun` from Cosmos, dataset cases from Blob.
- **Outputs**: writes `SampleTrace` blobs, scorecard summary to Cosmos, signed evidence bundle to Blob, audit events to Cosmos.
- **Termination**: emits `run.completed`/`run.failed`/`run.partial`/`run.cancelled`, then unconditionally invokes the deprovision step (FR-017). Exit codes: `0` clean, `1` failed-but-clean, `2` failed-with-orphans (reconciliation will pick up), `3` cancelled (after teardown).
- **Cancellation propagation**: `POST /api/eval/runs/{runId}/cancel` sets `runs.status = "cancelling"` in Cosmos. The runner polls this flag at every case-loop iteration; on detection it short-circuits to writing partial results, invoking `provisioner.deprovision`, and exiting with code `3`.
