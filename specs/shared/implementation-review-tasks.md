## Prioritized Findings

### 1. IMPORTANT / High: Publication and approval claims are manufactured, not established

The [publication contract](../037-capstone-evidence-pack/data-model.md#L19) requires a unique UUID v4, server-issued timestamp and identity, gate-passed publication, immutable snapshots, and dated revisions. Instead, the [generator fixes the date and sign-off](../../scripts/evidence_pack_gate/generate_artefacts.py#L27), [marks every manual row Validated](../../scripts/evidence_pack_gate/generate_artefacts.py#L41), and [assigns passed gate metadata and a deterministic UUID v5](../../scripts/evidence_pack_gate/generate_artefacts.py#L54). These are precisely the values in the [shared JSON header](feature-value-ledger.json#L4). The current ledger even includes [ADR-036-010](feature-value-ledger.json#L970), whose [authored date is 2026-05-22](../../docs/aidr/decisions/ADR-036-010-cycle-2-amendment-cycle.md#L5), while retaining the May 11 publication timestamp. This is a provenance inconsistency, not a reconstructed publication history.

The [publisher body](../../apps/api/app/services/governance/evidence_pack_writer.py#L50) does not call schema, link, or cap validation; each persistence writer is optional. The generator writes the current shared files directly at [its output boundary](../../scripts/evidence_pack_gate/generate_artefacts.py#L1121). The [historical API](../../apps/api/app/api/routes/governance/evidence_pack.py#L173) merely compares the requested ID with the current file. The [schema](../../packages/schemas/spec_037/feature-value-ledger.schema.json#L26) and [envelope model](../../packages/domain/src/domain/models/evidence_pack/evidence_pack_artefact.py#L24) also lack the promised `revises` representation. Impact: consumers can mistake authored snapshots for verified publications, and cannot obtain an earlier ledger version through this reader. Status: CONFLICT for the implementation contract; UNVERIFIED for actual publication, immutable storage, gate runs, human sign-off, and approvals. Follow-up: AUD-SHARED-001.
