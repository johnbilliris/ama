# HYP-042 — Human consultation record completeness for spec amendments

## Hypothesis

We believe that requiring a named human reviewer record for each amendment to this specification will produce sustained consultation-record completeness for this feature; we will know we are wrong if monthly audits find the completeness rate below the declared threshold within the measurement window.

## Preconditions

- A consultation log template with required fields (reviewer role, date, reviewed change link, disposition) is adopted for this feature.
- Amendment changes for this spec are traceable to merge commits or equivalent change records.

## Measurement Window

Rolling 90-day window, evaluated monthly.

## Falsification Criterion

- Consultation-record completeness < 90% for any monthly audit in the rolling 90-day window.
- Any amendment marked consulted that lacks a resolvable reviewed-change link.

## Status

Not tested
