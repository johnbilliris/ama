## Falsification

See front-matter `falsification_criterion`. Additional criteria:

- WCAG 2.2 AA regression on the mobile path (NFR-001) in any cycle.
- Operator workaround required to complete a P1 task (constitutes qualitative invalidation signal).

## Method

- **Type**: `rehearsal` (degraded-connectivity field rehearsal against the ASM-003 floor).
- **Cadence**: once per major mobile-surface release.
- **Data capture**: p95 situation-refresh latency, P1 task completion rate, operator-workaround count, accessibility-audit result.
- **Controls**: traffic-shaping to ≥ 64 kbps with ≤ 30-minute outage windows per ASM-003; same device profiles (ASM-008).
