## Falsification

See front-matter `falsification_criterion`. Additional criteria:

- Spoofed-authority content reaches an operator or a citizen surface without a provenance flag.
- Counter-message path exceeds agreed latency in either arm.

## Method

- **Type**: `A/B` (misinformation-injection rehearsal: arm A with countermeasure bundle, arm B with baseline).
- **Cadence**: one injection exercise per major release that changes the countermeasure bundle.
- **Data capture**: action-on-false-alert rate, detection latency, rebuttal-dispatch latency, adversarial-persona (P-ADV-MISINFO) scenario logs.
- **Controls**: identical injection sequence in both arms; same operator cohort; same scoring rubric.
