Build an Australia-focused, mobile-ready disaster response coordination hub with a responsive web and mobile experience, and a deterministic multi-agent orchestration backend using Microsoft Agent Framework (https://learn.microsoft.com/en-us/azure/architecture/ai-ml/idea/multiple-agent-workflow-automation). The implementation centers on authoritative hazard ingestion, explicit agent handoffs, human approval gates for safety-critical outputs, auditable coordination workflows, and jurisdiction-aware operating models for organisations and personas across Australia.
