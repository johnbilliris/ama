# spec-038 SC-009-AMEND pre-launch support baseline

This directory holds the **pre-launch support-ticket baseline** captured in the
2-week window immediately preceding spec-038 Help launch (per T-AA214).
Without this baseline, SC-009 (≥30% reduction in support tickets) is
unmeasurable.

Contents (populated by T-AA214):

- `pre-launch-support.md` — narrative summary + counts by persona + median TTR.
- `pre-launch-support.csv` — raw ticket-id → category → persona → TTR rows.

See `specs/038-help-docs-chat/spec.md §SC-009-AMEND`.
