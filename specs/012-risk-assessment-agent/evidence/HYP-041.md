# HYP-041 - BD capstone monsoon flood hypothesis for 012-risk-assessment-agent

## Hypothesis
We believe monsoon flood + cyclonic-flood risk-index calibration using BWDB + BMD data will produce risk-index calibration error <= 20% on out-of-sample historical flood events for the Bangladesh operator persona; we will know we are wrong if calibration error > 30% on out-of-sample BD events during BD monsoon Apr-Sep is observed in the measurement window (BD monsoon Apr-Sep).

## Preconditions
- Out-of-sample BD flood corpus prepared (>=10 historical events).
- BD hazard-class taxonomy ratified.
- D-009 cleared.

## Measurement Window
BD monsoon Apr-Sep.

## Falsification Criterion
- calibration error > 30% on out-of-sample BD events during BD monsoon Apr-Sep.
