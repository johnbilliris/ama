# HYP-040 - JP capstone subduction-zone earthquake / tsunami hypothesis for 012-risk-assessment-agent

We believe subduction-zone earthquake + tsunami risk-index calibration using JMA + JSHIS data will produce risk-index calibration error <= 10% on out-of-sample historical earthquake events for the Japan operator persona; we will know we are wrong if calibration error > 20% on out-of-sample JP events during quarterly review is observed in the measurement window (JP continuous; quarterly review).

- JP hazard-class taxonomy ratified.
- D-009 cleared.

## Measurement Window
JP continuous; quarterly review.

## Falsification Criterion
- calibration error > 20% on out-of-sample JP events during quarterly review.
